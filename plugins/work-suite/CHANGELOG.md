# Work Suite changelog

## 2.1.1 — 2026-08-25

Work Suite now consumes Plain Language 0.1.1, whose runtime contract is limited to reader outcomes, preserved meaning, and destination-appropriate voice.

## 2.1.0 — 2026-08-25

Work Suite now ships with the read-only upstream source steward for its Plain Language and Ponytail dependencies. The steward reports current, forward-no-payload-change, `needs-human-approval`, or blocked status without modifying vendored source or lock state.

## 2.0.0 — 2026-08-25

Work Suite now depends on unmodified Ponytail 4.9.0 and removes universal workflow ceremony: clear work goes directly to implementation, planning and review scale with risk, tests stay falsifiable rather than blanket, and terminal delivery still includes merge, release or install refresh, smoke, cleanup, and continuation.

## 1.6.0 — 2026-08-24

Work Suite now depends on Plain Language 0.1.0 so normal worker launches apply reader-centered output guidance without changing implementation workflow behavior.
